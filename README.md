# System design: архитектура приложений

Учебное издание к дисциплине «Технология разработки и защиты баз данных».
Автор — Макаров Максим Николаевич.

Справочник о том, как из отдельных программ собирается работающий сервис:
балансировщик, ограничение частоты запросов, серверы приложения, PostgreSQL,
MongoDB, Redis, объектное хранилище, очереди. Продолжает
[справочник по MongoDB](https://maximbytecamp.github.io/mongodb_theory_makarov/).

## Устройство

```
index.html            обложка и содержание
styles.css            вёрстка книги (каркас общий со справочником по MongoDB)
book.js               увеличение картинок, кнопка «копировать»
data/components.js    каталог деталей схемы — один источник для палитры и каталога
data/cases.js         заявки компаний: письма, правила проверки, сущности
katalog/              каталог деталей
praktikum/index.html  описание практикума «Архитектор по заявке»
praktikum/stol.html   конструктор схем
praktikum/engine.js   проверка схемы по правилам (без интерфейса)
praktikum/stol.js     доска, палитра, письма, отчёт
PLAN.md               карта книги
```

Сайт статический: открывается двойным кликом по `index.html`, публикуется
на GitHub Pages как есть, без сборки.

## Как добавить заявку

Заявка — объект в `data/cases.js`: три письма, у первого и третьего —
правила проверки схемы (`check(G)`), у второго — сущности с ответами
`best` / `ok` / `also`. Помощник `G` описан в начале `praktikum/engine.js`.
Новая деталь добавляется в `data/components.js` и сразу появляется в палитре
и в каталоге.
